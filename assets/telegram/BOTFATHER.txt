# BotFather — copy-paste values

Paste these into @BotFather (send each when prompted). Save this file; the
token you get back is a secret and must go only into Railway.

## 1. Create the bot
Send:  /newbot

Name (display name — shown in chat):
Brief

Username (must end in "bot", must be globally unique):
BriefInfoBot
(if taken, try: BriefLiveBot, BriefKenyBot, BriefAppBot — pick one and remember it)

You will get a token like: 7123456789:AAH...xYz
That is TELEGRAM_BOT_TOKEN. Do NOT share it.

## 2. Set the description (send /setdescription, then choose the bot)
Brief turns what your community posts on Telegram into real things you can find,
trust and act on — events, places, services and opportunities near you. Post a
message here and Brief extracts the real facts: what it is, where, when, how much.

## 3. Set the about (send /setabouttext)
A live layer over your city. Post, and Brief does the rest.

## 4. Set the profile picture (send /setuserpic, then choose the bot)
Upload: assets/telegram/bot-avatar-512.png

## 5. Set the commands (send /setcommands, then choose the bot, then paste):
start - What Brief is and how to post
help - How your message becomes a thing to act on

## 6. Group vs channel access (send /setjoingroups)
Leave as-is if you plan to add the bot to a CHANNEL (Brief ingests channel_post
updates). If you only want per-user DMs, set to: Disable — so the bot is never
added to groups. A human admin must add the bot to any channel it should read.
