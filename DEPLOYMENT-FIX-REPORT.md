# Deployment Fix Report — production frontend serving

## Why the frontend was not being served

The Railway deployment was starting the Express server correctly (server_started,
port 8080, env production), but Express exposed **only API routes**. The compiled
React/Vite frontend lives in `preview/dist`, yet nothing served it:

- no `express.static(...)` pointed at the build output,
- no SPA fallback returned `index.html` for client-side routes,
- and the production client calls the API under the `/ingest` prefix (which the
  dev server strips with a Vite proxy), but Express had no equivalent, so even
  once the shell was served its API calls would have 404'd.

Result: `/` and every route returned Express's default `Cannot GET /`.

## Files changed

| File | Change |
|---|---|
| `server/src/index.js` | Added `FRONTEND_DIST` (resolved from `import.meta.url`), `/ingest` prefix stripping, and production static serving + SPA fallback. |
| `railway.json` | Added `build.buildCommand: "npm run build:client"` so the Vite build runs at deploy time. |

## Final frontend dist path

`<repo>/preview/dist` — resolved absolutely from the server source location:

```js
const FRONTEND_DIST = path.resolve(
  path.dirname(fileURLToPath(import.meta.url)), // server/src
  '..', '..', 'preview', 'dist'
);
```

Correct regardless of whether the process starts from `/app`, `/app/server`, or
any other working directory.

## Final Express serving / fallback configuration

Production only (a no-op when `NODE_ENV !== 'production'` or the build is
absent), registered **after all `/api/*` routes**:

```js
if (servingFrontend) {
  app.use(express.static(FRONTEND_DIST, { index: false }));   // assets
  app.get('*', (req, res, next) => {
    if (req.path.startsWith('/api/')) return next();  // API miss → 404 as API
    if (req.path.includes('.')) return next();        // real asset → 404 if absent
    res.sendFile(path.join(FRONTEND_DIST, 'index.html'));      // SPA route
  });
}
```

Plus, before auth/routing, the production API prefix is normalised:

```js
app.use((req, _res, next) => {
  if (req.url.startsWith('/ingest')) req.url = req.url.slice('/ingest'.length) || '/';
  next();
});
```
